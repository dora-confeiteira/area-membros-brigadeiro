# Receitas de Brigadeiro sem Fogo! - Área de Membros

Área de membros exclusiva com receitas, apostilas PDF e calculadora de custos para confeiteiras.

## Funcionalidades

- **45+ Apostilas PDF** organizadas por categoria
- **Dicas Rápidas** de confeitaria
- **Calculadora de Custos** para precificação de produtos
- **Design Responsivo** para mobile e desktop
- **Salvamento Local** de receitas calculadas

## Categorias de Receitas

- Brigadeiros
- Recheios
- Bolos
- Doces Finos
- Geladinhos e Geleias
- Salgados e Massas
- Outros

## Como Usar no GitHub Pages

1. Faça upload desta pasta para um repositório no GitHub
2. Ative o GitHub Pages nas configurações do repositório
3. Acesse via `https://seu-usuario.github.io/seu-repositorio/`
